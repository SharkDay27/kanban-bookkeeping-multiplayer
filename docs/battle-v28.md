# v0.28.0 戰鬥與探索規則

每回合補至六張，未用牌保留，手牌通常最多八張。雙方以有效機動值決定双面骰數，正面數由高至低依序行動，同分隨機。被擊殺者取消該回合行動。攻擊與防禦先抵消正面数，再套用骰後增傷、抗性、易傷、恐怖與護盾。機動與攻防動畫依同一結算順序播放。

每名罪人六個技能，其中兩個使用單張卡面條件，其餘使用罪孽累計點數；一場最多學三個。攻擊技能增加當下骰數，特殊技能保留個別效果；治療與支援使用防禦面。封印時不觸發技能。狀態通常最多九層。

| 狀態 | 效果 |
| --- | --- |
| 易傷 | 每層受到的攻擊傷害 +10%，最多 +60% |
| 流血／燒傷 | 每層回合末 2 傷害；燒傷另減一顆攻擊骰 |
| 麻痺 | 每層機動 -1；累積四層消耗四層、跳過行動，仍可防禦 |
| 封印 | 不能觸發技能，普通牌與能力牌可用 |
| 恐怖 | 造成攻擊傷害減半 |
| 震顫 | 每三層補牌目標與手牌上限各減一，最低補至三張 |
| 沉淪 | 每層骰子正面率 -5 個百分點，最低 20% |
| 增傷 | 至少擲一正面後，每層骰後傷害 +2，最多 +12 |
| 護盾 | 施加時每層獲得四點額外護盾 |
| 再生 | 每層回合末恢復三 HP，不能復活 |
| 靈敏 | 每層機動 +1 |
| 刻印 | 辛克萊每次增加一層，隨機戰鬥／穩定／機動加成，最高 +3，本場有效 |

堂吉訶德本場第三次治療後，接下來兩回合自動選牌及確認；接管期間不觸發治療技能。格里高爾破壞敵方牌每場最多三張。鴻璐技能額外金幣每場最多二十四。武器每回合首次造成傷害施加流血、沉淪或震顫。

補給與休整合併成個人「休整」節點，每位玩家選補給（隨機一件裝備／消耗品）、小歇或替隊友療傷。小歇與療傷依初中高級恢復目標生命上限 34%／28%／24%，選項顯示受治療修正後的實際 HP。多人倒下角色在下一節點以一 HP 復活；所有玩家死亡才失敗。危險度只由危機事件改變，達到上限不直接失敗。

各非初始稀有度追加兩件武器、兩件防具及兩件飾品，共十八件；防具同時提供少量属性修正、生命與初始護盾。

驗證：`npm test` 與 `npm run check`，包括先手擊殺／敵先手擊殺、卡面精確條件、牌堆所有權、狀態閾值、封印、接管、復活、個人休整、裝備數量與手機確認按鈕穩定性。
